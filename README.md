# distance-calculator

This Python program calculates the distance between two points on a coordinate plane using the distance formula

How to Run the Program: 
Make sure Python is installed on your computer. 
Save the program as distance.py. 
Open a terminal or command prompt in the program's folder. 
Run the program with .py

Input Needed: 
x1 — x-coordinate of the first point 
y1 — y-coordinate of the first point 
x2 — x-coordinate of the second point 
2 — y-coordinate of the second point

Sample Output: 
Enter x1: 1 
Enter y1: 2 
Enter x2: 4 
Enter y2: 6 
5.0
